## Features

- ChatGPT-like interface with dark theme
- Model badge with animated status indicator
- Sidebar with conversation history
- New chat & delete conversation
- Typing indicator while waiting for responses
- Lightweight markdown rendering
- Suggestion cards on the welcome screen
- Fully responsive (desktop + mobile)
- Zero dependencies — single HTML file

---

## How to Use

1. Open the [live demo](https://youssefth98.github.io/Claude-Fable-5.1/)
2. Type your message and press **Enter**
3. Conversations are automatically saved in your browser

> **Note:** The first time you use it, Puter.js may ask you to sign in. This is required to access the AI models.
